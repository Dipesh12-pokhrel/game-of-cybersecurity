Put replacement assets here.

Anything in this folder is served from the site root in both `npm run dev`
and `npm run build`, so `public/textures/floor.jpg` is available at
`/textures/floor.jpg`.

Suggested layout:
  public/textures/   image textures
  public/models/     .glb / .gltf models
  public/360/        equirectangular 360 photographs
  public/audio/      recorded sound effects
  public/vendor/     a local copy of aframe.min.js for offline use

See "Replacing the assets" in README.md.
